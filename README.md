# 东坡行旅 · 苏轼诗词地图 Demo

当前版本包含两层数据：

- 公版古典总库：763,547 篇、28,156 位作者
- 苏轼专题：3,165 篇，其中 363 篇具有编年地点或生平推定地点

公版总库按朝代分布：

- 唐 50,784 篇
- 宋 299,406 篇
- 元 37,378 篇
- 明 252,694 篇
- 清 107,791 篇
- 另含先秦、秦汉、魏晋、南北朝、隋、辽、金

页面以全屏地图为主：地点标记先聚合该地作品数量，点击地点后显示该地诗词，再进入单首作品。苏轼专题可用底部时间轴筛选 1037—1101 年；选择其他朝代、作者、体裁或关键词后，地图会同步展示对应地点。

右上角“总库”入口通过本地 SQLite/FTS5 索引提供分页检索：

- 诗 709,284 首
- 词 54,013 首
- 曲 250 首
- 可按朝代、作者、体裁、题目或正文筛选
- 地图地点与上述筛选同步更新

总库来自 `Cohenjikan/shiyun-corpus` 的公开 PD 层，保留来源字段和上游的 canonical/重复标记。现代及当代受版权限制的隔离层没有导入。

地点标注分为明确地点、高/中/低置信推定。其余完全无系年、无地名依据的作品只进入全集检索，不虚构地图坐标。

全库地图目前完成第一层保守标注：维护 78 个古今地点及别名，只对题目中明确出现地名的作品建立“作品相关地点”关联。约 3.2 万篇作品命中；它不等于精确创作地，界面会明确显示这一限制。下一层才会逐步引入作者年谱和可靠系年。

全集 3,165 篇均生成了基础导读字段，包括主题、核心意象、人话导读和阅读提示。基础导读由确定性规则生成并明确标注，不冒充专家逐篇校注。

## 本地运行

克隆仓库及苏轼专题子模块：

```bash
git clone --recurse-submodules https://github.com/qiuwuyiye/su-shi-poetry-map.git
cd su-shi-poetry-map
```

安装前端依赖：

```bash
npm ci
```

从仓库的 `data-v1` Release 下载 `corpus.db` 并放在项目根目录。使用 GitHub CLI 时：

```bash
gh release download data-v1 --pattern corpus.db
```

也可以从公开语料重新构建：

```bash
git clone https://github.com/Cohenjikan/shiyun-corpus.git .source/shiyun-corpus
python3 scripts/build_global_corpus_db.py
```

启动服务：

```bash
python3 serve_demo.py
```

打开 <http://127.0.0.1:8765>。

使用专门的本地服务器，是因为 Cursor 生成的图片位于会话资源目录；`serve_demo.py` 会将网页和配图映射到同一地址下。若资源目录改变：

```bash
POETRY_MAP_ASSET_DIR=/path/to/assets python3 serve_demo.py
```

`corpus.db` 是约 912MB 的生成产物，不纳入 Git 历史；`.source/shiyun-corpus` 同样不入库。仓库只保存应用代码、苏轼专题数据和可复现的构建脚本。

## 数据口径

- 年龄统一采用虚岁，并在界面明确标注。
- 坐标分为“景点级”和“城市级示意”，不把城市中心误写为精确创作点。
- 《念奴娇·赤壁怀古》的地点是黄州赤鼻矶，并非三国赤壁大战遗址。
- 白话解读与史料说明分开，避免把现代阐释写成史实。
- 全集文本来自 `chinese-poetry`，通过 MIT 项目 `su-shi-chronicle` 的清洗结果接入；原始古籍文本属于公有领域。
- 当前暂停新增 AI 配图。已有两张意境图继续使用，其余作品显示视觉占位；27 张地图名篇的批处理清单保存在 `image-batch.json`。

## 下一步数据结构

全量化时，每首作品至少需要：

`作品正文 / 作者 / 朝代 / 体裁 / 创作年及置信度 / 年龄口径 / 古今地名 / 经纬度及精度 / 创作背景 / 白话解读 / 典故 / 资料来源 / 配图状态`

公开古诗词语料通常能覆盖作者、标题、正文，却很少同时具备可靠的创作时间、地点、年龄与背景。后四项需要从年谱、作品系年和权威注本中补齐，并保留“确定 / 主流观点 / 推定 / 未知”的证据等级。
